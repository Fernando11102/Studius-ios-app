# Studius – iOS Student Support App

Studius is my final-year Software Engineering project, developed as an iOS application to support university students with their academic life.

The application was designed as a digital companion for students and includes an AI-assisted feature integrated into the main dashboard.

## Features

- AI-powered assistant integrated into the application dashboard
- iOS user interface developed using SwiftUI
- Student-focused home dashboard
- Academic support functionality
- External API integration
- Designed and developed independently as my final-year project

## Tech Stack

- Swift
- SwiftUI
- Xcode
- API Integration
- iOS Development

## Project Background

I developed Studius as my final-year project for my BSc Software Engineering degree at the University of Westminster.

I worked on the project from the initial idea and requirements through to application design and implementation.

Through this project I developed experience in:

- Designing an iOS application from an initial concept
- Building interfaces using SwiftUI
- Integrating an external API
- Structuring application functionality
- Debugging and solving development problems
- Managing an individual software project

## AI Assistant

One of the main features of Studius is an AI assistant integrated into the application's home dashboard.

The assistant uses an external API to provide students with additional guidance.

API credentials should not be stored publicly in this repository.
